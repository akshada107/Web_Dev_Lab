# Web Dev Lab

A collection of web development practice projects built with HTML and CSS.

## Projects

- **Portfolio** — [`program/index.html`](program/index.html) with styles in [`program/style.css`](program/style.css)
- **P1 screenshot** — [`outputs/p1.png`](outputs/p1.png)
- **P2 screenshot** — [`outputs/p2.png`](outputs/p2.png)
- **P3 — Elsewhere stays** — [`program/p3.html`](program/p3.html) with styles in [`program/p3.css`](program/p3.css)

## Preview

From the `program` directory, start a local server:

```bash
python3 -m http.server 8000
```

Then open the page you want to view:

- Portfolio: <http://localhost:8000/index.html>
- P3: <http://localhost:8000/p3.html>
